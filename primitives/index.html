Primitives

Each primitive shown individually, with the minimum dependencies needed to make it visible.

Story

Axis & Time

timeline()
Draws the time axis, a horizontal or vertical line with one tick per scene. Provides sceneX, sceneY, and direction to every primitive that follows it. Scene labels and date strings are optional.
needs: nothing gives: sceneX · sceneY · direction
events()
Places a dot or diamond marker at each scene's position on the axis. Hoverable, shows the scene title in the tooltip. Requires timeline() to have run first.
needs: sceneX · sceneY gives: nothing shown with: timeline

Character Layout

characters()
layout: 'lane'
Each character gets a fixed parallel track (lifeline lane). Positions are static.
needs: sceneX · sceneY · direction gives: charPos · charRadius shown with: timeline
characters()
layout: 'force'
Characters cluster per-scene using a D3 force simulation. Nodes are draggable. The simulation is pre-settled so the initial layout is stable.
needs: sceneX · sceneY · direction gives: charPos · charRadius shown with: timeline
lifelines()
Connects a character's appearances across scenes with a continuous line. In force mode the lines track node positions live on every simulation tick.
needs: charPos gives: nothing shown with: timeline · characters(lane)
edges()
Directed lines between characters for each interaction. Multiple interactions between the same pair in the same scene are drawn as parallel offset lines. Arrowheads are optional. Hit area is wider than the visible line for easy hovering.
needs: charPos gives: nothing shown with: timeline · characters(force)

Global Network

network()
One node per character in a free-form force-directed layout. Aggregates all interactions across all scenes. Fully draggable. Pair with edges() to draw relationship lines.
needs: nothing gives: charPos · charRadius

Locations & Movement

locations()
Circular nodes for each visited location, auto-arranged or manually positioned. A dot tray below each node marks which scenes take place there. Draggable, movement() redraws paths live.
needs: nothing gives: locPos · locDotPos
movement()
Bezier arcs following scene order between location nodes. A midpoint arrowhead shows travel direction. Paths redraw live when location nodes are dragged.
needs: locPos gives: nothing shown with: locations
