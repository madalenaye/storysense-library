StorySense

Narrative visualization as composable building blocks.
You just need to pick the pieces you need, chain them together, and render. No framework and no build step.

Explore Primitives Examples

Quick start

import SS from './storysense-lib/src/index.js';

// 1. Load and normalize your story JSON
const raw   = await fetch('./story.json').then(r => r.json());
const story = SS.normalizeNarrative(raw);

// 2. Compose primitives and render
SS.storysense('#chart', story, { responsive: true, aspectRatio: 860/460 })
  .add(SS.tooltip())
  .add(SS.timeline({ direction: 'x' }))
  .add(SS.characters({ layout: 'lane', r: 14, labels: true }))
  .add(SS.lifelines())
  .render();

// CDN import (no download needed):
// import SS from 'https://cdn.jsdelivr.net/gh/madalenaye/storysense-library@main/src/index.js'
